## Blinkit Sales Dashboard using Power BI

## Project Overview
This project is an interactive Power BI dashboard developed during my internship to analyze Blinkit's sales data. The dashboard provides valuable business insights by visualizing sales performance, outlet analysis, customer ratings, and product trends through interactive charts and filters.

##  Objectives
- Analyze overall sales performance.
- Compare sales across different outlet types and locations.
- Identify top-performing product categories.
- Monitor key business KPIs.
- Build an interactive dashboard for data-driven decision-making.

##  Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel
  
##  Dashboard Features
- Total Sales
- Average Sales
- Total Items Sold
- Average Rating
- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Outlet Location
- Item Type Analysis
- Fat Content Analysis
- Top Selling Products
- Interactive Filters (Slicers)

##  Key Insights
- Tier 3 outlets generated the highest sales.
- Medium-sized outlets contributed significantly to revenue.
- Fruits & Vegetables and Snack Foods were among the top-selling categories.
- Supermarket Type 1 recorded the highest sales.

##  Learning Outcomes
- Built interactive dashboards using Power BI.
- Applied Power Query for data cleaning and transformation.
- Used DAX to create business KPIs.
- Improved data visualization and analytical skills.
